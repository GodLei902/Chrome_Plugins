# 社交评论清理器操作手册

适用版本：`2.0.0`

## 一、安装教程

安装前先将收到的 ZIP 压缩包解压到一个容易找到的文件夹。安装时要选择“解压后的文件夹”，不能直接选择 ZIP 文件；所选文件夹内应能看到 `manifest.json` 文件。

### 1. 系统自带 Chrome 浏览器

1. 打开 Chrome，在地址栏输入 `chrome://extensions` 并回车。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择刚才解压、且包含 `manifest.json` 的文件夹。
5. 看到“社交评论清理器”后，点击浏览器右上角的拼图图标，将它固定到工具栏。

### 2. HubStudio 指纹浏览器

1. 打开 HubStudio，创建或打开一个使用 Chrome 内核的浏览器环境。
2. 在该环境的浏览器地址栏输入 `chrome://extensions` 并回车。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。如果没有这个入口，请在扩展管理页面选择“加载本地扩展”。
4. 选择包含 `manifest.json` 的解压文件夹。
5. 返回该浏览器环境，确认工具栏中可以看到扩展图标。

### 3. BitBrowser 指纹浏览器

1. 打开 BitBrowser，创建或打开一个使用 Chrome 内核的浏览器环境。
2. 在该环境的浏览器地址栏输入 `chrome://extensions` 并回车。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。如果没有这个入口，请在扩展管理页面选择“加载本地扩展”。
4. 选择包含 `manifest.json` 的解压文件夹。
5. 返回该浏览器环境，确认工具栏中可以看到扩展图标。

提示：每个指纹浏览器环境相互独立。如果要在多个环境使用，需要在每个环境中分别安装一次。

## 二、开始前准备

1. 使用 Chrome 浏览器，并确认已经登录有权限管理评论的 Instagram 或 TikTok 账号。
2. 准备好要处理的完整内容链接：Instagram 帖子或 Reels，或 TikTok 作品页。
3. 第一次使用时，建议先用测试账号或测试帖子试运行。

### 平台范围和权限

- Instagram：使用完整帖子或 Reels 链接。
- TikTok：使用完整作品页链接 `https://www.tiktok.com/@<creator>/video/<id>`；不支持短链、个人主页或跳转页。
- 扩展只使用设置/检查点存储、目标标签页和续跑提醒权限；只会在 Instagram 现有域名及 `www.tiktok.com` 页面注入内容脚本。

TikTok 已完成代码与自动化接入，但尚未完成真实页面验收；Preview、单条删除、分页、刷新恢复与 Pause/Stop 仍需要测试账号验证。正式使用前必须先进行小批量 Preview；自动化测试不代表真实平台删除已经验证成功。

## 三、填写设置

点击 Chrome 工具栏中的“社交评论清理器”图标，填写以下内容：

- **清理平台**：选择 Instagram 或 TikTok；目标链接必须属于所选平台。
- **目标内容 URL**：填写完整的 Instagram 帖子/Reels 或 TikTok 作品页链接。TikTok 只接受 `https://www.tiktok.com/@<creator>/video/<id>` 格式，不接受短链或个人主页。
- **白名单用户名**：每行填写一个不希望处理的用户名，可填写或不填写 `@`。
- **删除关键词**：每行填写一个关键词。评论回复中包含任意一个关键词，就会进入处理名单。

其他设置先使用默认值即可。设置会自动保存。

## 四、先预览

1. 点击“预览模式”。
2. 等待目标平台页面打开并完成扫描。
3. 查看页面提示的候选数量，确认关键词和白名单设置正确。

预览模式只统计，不会删除任何内容。

## 五、正式处理

确认预览结果无误后：

1. 点击“开始”。
2. 等待任务自动运行，不要重复点击按钮。
3. 当前一轮评论处理完成后，任务会显示“等待下一轮”，随机休息 10～60 分钟，然后绕过页面缓存刷新并继续，不需要重复点击“开始”。
4. 需要暂时停下时点击“暂停”；确定结束整个持续任务时点击“停止”。停止后不会自动刷新或恢复。

系统只处理命中关键词的回复，不删除一级评论；白名单账号和内容作者的回复会被保留。

TikTok 页面会先切换到唯一的评论页签，再逐个展开一级评论的回复。遇到重复评论面、菜单、删除入口、确认弹层或无法验证的删除结果时，系统会暂停，不会猜测继续。

## 七、悬浮面板

打开目标页面后，右侧默认只显示贴在边缘的标签式入口。点击入口可打开完整面板。

- 标题栏“—”：最小化面板，任务继续运行。
- 标题栏“×”或标签入口旁的“×”：关闭当前页面控件。任务运行中会先确认，点击“关闭并暂停”会保存进度并暂停；点击“取消”保持运行。
- 长按标签入口约半秒后拖动，松开会吸附到最近的屏幕边缘；短按仍会打开面板。
- 关闭仅作用于当前标签页，刷新页面后仍保持关闭；再次点击配置页的“开始”或“预览模式”会重新打开，其他标签页不受影响。

## 八、遇到问题怎么办

- **没有扫描到内容**：检查链接是否正确，并确认评论已经在页面中显示。
- **任务自动暂停**：可能是账号权限、网络或当前平台页面提示异常。先处理页面提示，再重新运行。
- **页面自动刷新**：这是本轮完成后的正常续跑流程，刷新只针对目标页面并绕过页面缓存，不会清理其他网站的缓存。
- **不确定是否会误删**：立即点击“停止”，修改白名单或关键词后重新预览。

请勿在 Instagram 或 TikTok 出现验证、限流或安全提醒时继续操作。TikTok 的 Preview、单条删除、分页、刷新恢复以及 Pause/Stop，必须先在测试账号和本人可管理的作品上小批量验证。
