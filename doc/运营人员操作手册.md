# 社交评论清理器操作手册

适用版本：`1.0.0`

## 一、安装教程

安装前先将收到的 ZIP 压缩包解压到一个容易找到的文件夹。安装时要选择“解压后的文件夹”，不能直接选择 ZIP 文件；所选文件夹内应能看到 `manifest.json` 文件。

### 1. 系统自带 Chrome 浏览器

1. 打开 Chrome，在地址栏输入 `chrome://extensions` 并回车。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择刚才解压、且包含 `manifest.json` 的文件夹。
5. 看到“社交评论清理器”后，点击浏览器右上角的拼图图标，将它固定到工具栏。

### 2. HubStudio 指纹浏览器

1. 打开 HubStudio，创建或打开一个使用 Chrome 内核的浏览器环境。
2. 在该环境的浏览器地址栏输入 `chrome://extensions` 并回车。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。如果没有这个入口，请在扩展管理页面选择“加载本地扩展”。
4. 选择包含 `manifest.json` 的解压文件夹。
5. 返回该浏览器环境，确认工具栏中可以看到扩展图标。

### 3. BitBrowser 指纹浏览器

1. 打开 BitBrowser，创建或打开一个使用 Chrome 内核的浏览器环境。
2. 在该环境的浏览器地址栏输入 `chrome://extensions` 并回车。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。如果没有这个入口，请在扩展管理页面选择“加载本地扩展”。
4. 选择包含 `manifest.json` 的解压文件夹。
5. 返回该浏览器环境，确认工具栏中可以看到扩展图标。

提示：每个指纹浏览器环境相互独立。如果要在多个环境使用，需要在每个环境中分别安装一次。

## 二、开始前准备

1. 使用 Chrome 浏览器，并确认已经登录有权限管理评论的 Instagram 账号。
2. 准备好要处理的帖子或 Reels 链接。
3. 第一次使用时，建议先用测试账号或测试帖子试运行。

## 三、填写设置

点击 Chrome 工具栏中的“社交评论清理器”图标，填写以下内容：

- **目标帖子 URL**：填写完整的 Instagram 帖子或 Reels 链接。
- **白名单用户名**：每行填写一个不希望处理的用户名，可填写或不填写 `@`。
- **删除关键词**：每行填写一个关键词。评论回复中包含任意一个关键词，就会进入处理名单。

其他设置先使用默认值即可。设置会自动保存。

## 四、先预览

1. 点击“预览模式”。
2. 等待 Instagram 页面打开并完成扫描。
3. 查看页面提示的候选数量，确认关键词和白名单设置正确。

预览模式只统计，不会删除任何内容。

## 五、正式处理

确认预览结果无误后：

1. 点击“开始”。
2. 等待任务自动运行，不要重复点击按钮。
3. 需要暂时停下时点击“暂停”；确定结束本次任务时点击“停止”。

系统只处理命中关键词的回复，不删除一级评论；白名单账号和帖子作者的内容会被保留。

## 六、遇到问题怎么办

- **没有扫描到内容**：检查链接是否正确，并确认评论已经在页面中显示。
- **任务自动暂停**：可能是账号权限、网络或 Instagram 页面提示异常。先处理页面提示，再重新运行。
- **不确定是否会误删**：立即点击“停止”，修改白名单或关键词后重新预览。

请勿在 Instagram 出现验证、限流或安全提醒时继续操作。
