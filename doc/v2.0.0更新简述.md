# 社交评论清理器 v2.0.0 更新简述

- 新增悬浮标签面板：目标页面默认显示边缘入口，支持展开、最小化、关闭确认和长按拖动吸附；关闭状态只保留在当前标签页。
- 新增持续清理续跑：本轮完成后会按随机间隔刷新目标页面并继续下一轮；暂停可保存进度，停止会结束续跑。
- 优化评论与回复加载：自动展开当前可见的回复入口，配合评论容器自然滚动与加载状态判断，减少评论未加载完就结束扫描的情况。
- 优化预览和正式处理流程：两种模式使用统一的串行定位与处理节奏；预览仍只扫描和统计，不会打开删除菜单或修改页面。
- 优化 Instagram 控件定位：增加结构化和多语言控件识别，改善中文、日文等界面的回复展开、评论定位和悬停出现的菜单操作。
- 增加平台插件基础：加入平台契约、注册中心和 Instagram 地址识别，为后续接入其他平台做准备；当前正式支持范围仍为 Instagram。
- 强化运行保护：持续使用白名单、帖子作者和一级评论保护；当目标、菜单或删除结果无法明确确认时，任务会暂停而不继续操作。

使用前请先在测试账号执行预览，并以小批量确认页面效果。静态测试和安装包校验不代表已完成真实 Instagram 删除验收。
