# 社交评论清理器使用手册

## 一、插件简介

社交评论清理器是一个 Chrome 扩展，用于清理指定 Instagram 帖子或 Reels 下命中关键词的评论和回复。

扩展只操作当前浏览器中已经登录的 Instagram 页面，不读取、不保存或上传账号密码，也不调用 Instagram 私有 API。页面结构、账号权限或网络状态异常时，扩展会暂停，不会猜测点击其他操作。

## 二、如何安装

1. 使用 Chrome 打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录，也就是包含 `manifest.json` 的目录。
5. 确认扩展列表中出现 **社交评论清理器**，版本号为 `1.0.0`。

安装完成后，可以点击 Chrome 工具栏上的拼图图标，将社交评论清理器固定到工具栏。

### 生成安装包

在项目根目录执行：

```bash
npm run package
```

命令会在 `dist/` 目录生成当前版本的 ZIP 安装包。发布时，在 Chrome 扩展页面选择“加载已解压的扩展程序”仍应选择源码目录；ZIP 文件用于分发或提交到扩展商店。

首次使用请先在配置弹窗中填写目标帖子 URL 和清理规则。

## 三、如何打开设置页

在 `chrome://extensions` 中找到社交评论清理器，点击“详细信息”，再点击“扩展程序选项”。也可以右键工具栏中的扩展图标，选择“选项”。

## 四、首次配置

点击工具栏上的扩展图标即可直接打开配置弹窗，链接、白名单、关键词和频率参数都在这里填写。配置会自动保存，也可以从扩展详情页打开同一设置页。

### 基本设置

- **平台**：当前仅支持 Instagram。
- **目标帖子 URL**：填写要处理的单个帖子或 Reels 的完整地址，例如：
  - `https://www.instagram.com/p/短代码/`
  - `https://www.instagram.com/reel/短代码/`
- **白名单用户名**：每行一个用户名，可以带或不带 `@`。用户名比较不区分大小写。
- **删除关键词**：每行一个普通文本关键词。评论文本包含任意关键词时，会成为候选项；匹配不区分大小写。

目标地址必须是 Instagram 的 `/p/` 或 `/reel/` 地址。查询参数、哈希和末尾斜杠会自动规范化，但帖子类型和短代码必须正确。

### 运行设置

填写完成后点击“开始”执行持续清理，或点击其右侧的“预览模式”只扫描并统计候选评论。点击按钮后会先自动打开目标帖子页面，等页面加载完成再开始对应任务；如果 URL 不完整、刷新休息时间不在 10～60 分钟内，或任意一组最小值大于最大值，页面会提示错误。

## 五、推荐使用流程

### 1. 先准备测试内容

建议使用测试账号、测试帖子或临时评论验证规则。确认当前 Chrome 已登录有权管理目标评论的 Instagram 账号。

### 2. 使用预览模式

1. 填写目标帖子 URL、白名单和关键词。
2. 点击“预览模式”按钮，只扫描并统计候选评论。
3. 扩展会自动打开或切换到对应的目标帖子页面。
4. 等待 Instagram 页面加载完成，在右下角找到“社交评论清理器”面板。
5. 页面就绪后会自动开始预览扫描。

连续加载是内置策略，面板会自动滚动评论容器或点击可见的加载入口，并显示累计一级评论、累计回复、加载轮次和无新增重试次数。预览模式不会打开评论菜单、不会执行删除；白名单回复、帖子作者回复和未命中关键词的回复会被跳过。每一批之间会使用现有随机延迟算法自动休息。

### 3. 执行正式删除

确认预览结果无误后，在配置页点击“开始”。扩展会自动跳转到目标页面，页面加载完成后立即扫描并自动处理符合规则的评论；无需再点击页面面板中的“开始”或删除确认。

正式运行只删除命中的子级回复，一级评论永远不会删除。每次删除成功后会重新扫描并重建候选，连续处理 20 条后按休息时间边界随机暂停，时间到后自动继续；当前批次没有候选时会在批次之间随机休息，然后自动滚动或点击入口加载下一批。当本轮确认没有待处理候选且没有更多可加载评论后，任务进入“等待下一轮”休息态，随机等待 10～60 分钟，再绕过页面缓存刷新目标帖子并自动继续。也可以点击“暂停”暂存进度，点击“继续”恢复，点击“停止”终止整个持续任务；停止后不会自动刷新或恢复。

## 六、默认限制与高级参数

高级设置用于控制所有 Instagram 标签页共用的操作次数上限，所有数值都必须大于 0。页面结构或权限出现异常时，任务会直接暂停。

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 删除间隔（平均/最小/最大） | 18 / 12 / 30 秒 | 两条删除操作之间的随机等待时间 |
| 删除前等待（平均/最小/最大） | 20 / 5 / 25 秒 | 删除菜单出现后到点击删除按钮前的随机等待时间 |
| 连续处理后休息 | 20 条 | 连续成功处理 20 条后进入休息 |
| 休息时间（平均/最小/最大） | 60 / 45 / 90 秒 | 达到连续处理上限后的随机休息时间 |
| 会话最大删除数 | 100 / 不限 | 选择“不限”时由限频和其他安全异常控制 |
| 本轮完成后的刷新休息 | 10～60 分钟，默认平均 30 分钟 | 本轮完成后随机等待，之后绕过页面缓存刷新并继续 |
| 会话最长时间 | 0（不限） | 填写正数时作为额外安全上限 |
| 连续加载策略 | 始终开启 | 预览和正式运行均自动进入下一批；按实际新增评论 ID 计数 |
| 批次间休息 | 内置随机 | 使用现有随机延迟算法，避免固定节奏 |
| 连续加载边界 | 内置 | 最大批次、无新增重试和滚动稳定等待不开放配置 |
| 全局限频（每分钟/每小时） | 5 / 60 次 | 所有打开的 Instagram 标签页共用 |

除非明确了解账号和页面风险，否则不要将间隔调得过短，也不要取消会话上限。

## 七、规则说明

- 未填写删除关键词时，只进行扫描和预览，不会删除任何评论。
- 白名单优先级最高。白名单用户名的评论永远不会删除。
- 帖子作者自己的一级评论和回复永远不会删除。
- 一级评论永远不会删除；只处理当前 DOM 已加载的子级回复，避免未知级联回复被连带删除。
- 连续加载策略会在当前评论容器内滚动到底部或点击可见加载入口；以新增评论 ID 判断是否进入下一批，不读取或重放 Instagram 接口。
- 预览模式只扫描不删除；正式运行会先处理当前批次，再自动加载下一批。
- 删除菜单、删除项或确认按钮无法可靠识别时，扩展会暂停并显示原因。
- 同一条帖子同时只能在一个标签页中运行。

## 八、常见问题

### 页面没有出现控制面板

检查设置页是否已填写目标 URL、当前页面是否与目标 URL 完全匹配，并刷新页面等待 Instagram 加载完成。

### 扫描结果为 0

确认评论已经加载、关键词没有多余空格，并检查关键词是否确实出现在回复文本中。连续加载会自动运行；若页面没有可滚动评论容器或连续三次没有新增 ID，本轮会进入刷新休息，不会结束持续任务。

### 点击确认后暂停

常见原因包括账号没有删除权限、Instagram 弹出验证或限流提示、网络异常，或 Instagram 页面结构发生变化。根据面板中的错误信息处理后，再重新打开目标页面尝试；不要在出现验证或限流时连续重试。

### 提示帖子正在另一标签页运行

停止另一标签页的会话，或关闭该标签页后再重新开始。同一条帖子同时只能有一个运行会话。

### 如何取消自动处理

在 Instagram 页面点击“停止”即可结束当前会话。

### 为什么页面会自动刷新

正式任务每一轮处理完成后会进入随机休息，等待时间在 10～60 分钟内。休息结束后扩展只刷新目标页面并绕过页面缓存，不会清理其他网站的浏览器缓存；页面加载完成后会恢复同一会话，已处理的回复不会重复删除。

## 九、安全建议

- 先用测试账号和预览模式确认规则，再处理真实内容。
- 白名单中加入必须保留的账号，尤其是重要合作方或管理员账号。
- 不要在出现账号验证、限流或挑战页面时继续操作。
- 定期检查关键词和目标 URL，避免误配置到其他帖子。
- 扩展只应从可信的本地源码目录加载；不需要向任何人提供 Instagram 登录信息。
